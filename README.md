# Peptidinfo

Informationshubb för peptider med fokus på SEO, tillförlitlighet och enkel uppdatering.

## Setup

1. npm install
2. npm run dev
3. Öppna http://localhost:3000

## Funktioner

- Skandinavisk, enkel design
- Searchable bibliotek
- SEO-optimera metataggar
- Möjlighet att lägga till nya artiklar (bloggar) snabbt
